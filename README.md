# Заботливая услуга — WEB2

Самостоятельный сайт на Node.js: девять основных страниц, политика конфиденциальности, обработка персональных данных и отдельная админка. Первая версия `WEB` и исходные материалы сохранены.

## Запуск

Нужен Node.js 22 или новее. Установка библиотек не требуется. Команды выполняются из папки WEB2:

```sh
node tools/build.mjs
node tools/server.mjs
```

Сайт: http://127.0.0.1:4174/

Админка: http://127.0.0.1:4174/admin/login.html

При первом локальном входе создайте свой логин и пароль. На публичном хостинге аккаунт создаётся командой `node tools/admin-user.mjs --username admin`. Готового общего пароля в проекте нет. Инструкции по размещению, HTTPS и сохранению данных: [ADMIN.md](ADMIN.md).

## Админка

Редактируются тексты и ссылки всех страниц, обе таблицы статистики, документы, изображения, галереи, контакты, свободные места и дата сведений. Можно загружать файлы, менять порядок изображений, добавлять блоки. Перед публикацией доступен предпросмотр. Предыдущая версия сохраняется автоматически; восстановление доступно в истории.

Индивидуальные ответы и пожелания опроса находятся в разделе «Ответы на опрос». Первичные анкеты автоматически удаляются через 90 дней; обезличенные итоговые счётчики остаются. Публичная страница показывает только итоговые числа и проценты по пяти вопросам. Пожелания доступны только администратору. Технический cookie на 24 часа ограничивает повторное участие в одном браузере.

## Отправка формы

Кнопка «Отправить» отправляет сообщение через сервер на `zabota-usluga72@mail.ru`. Для реальной отправки настройте на сервере `SMTP_USER` и `SMTP_PASSWORD` — отдельный пароль приложения Mail.ru. Остальные настройки и проверка описаны в [MAIL.md](MAIL.md). Пароль не должен находиться в HTML или репозитории.

Без настроенного SMTP сервер сообщает об ошибке и сохраняет введённый текст в форме; подтверждения отправки нет. Реальная доставка в почтовый ящик требует проверки после настройки доступа Mail.ru.

## Размещение и данные

Для всех функций загрузите на Node.js-хостинг папку WEB2 целиком и запустите `node tools/server.mjs` или `npm start`. Настройте HTTPS, `HOST`, `PORT`, `ADMIN_PUBLIC_ORIGIN`. Простая загрузка одного `dist` даёт только просмотр статических страниц: форма, опрос и админка требуют сервер.

- `dist` — страницы, стили, сценарии, локальный Onest, изображения и оригиналы документов.
- `tools/pages.mjs`, `sections.mjs`, `legal.mjs` — шаблоны и исходные тексты.
- `content.json` — исходные данные; сохранения админки не перезаписывают их.
- `cms-content.json` — опубликованные изменения после первого сохранения.
- `.admin` — хеш пароля, история версий и приватные анкеты; сервер не раздаёт эту папку.
- `dist/assets/uploads` — загруженные документы и изображения. Старые файлы сохраняются для восстановления версий.

Сохраняйте `.admin`, `cms-content.json` и `dist/assets/uploads` при обновлении приложения. Резервная копия только HTML не сохраняет учётную запись и историю.

## Удобство и проверка

Крупный текст, широкая контентная область, локальный шрифт Onest, заметная плашка свободных мест. Первый экран обычной версии вписывается в десктопное окно вместе с плашками. При увеличении текста блоки свободно растут, таблицы прокручиваются внутри своих областей.

Панель чтения открывается поверх текущего места страницы. Доступны текст до 200%, три контрастные схемы, межстрочные интервалы, подчёркивание ссылок и скрытие декора. Настройки сохраняются в браузере.

PDF открываются в отдельной вкладке. Слайдеры имеют заметные стрелки по бокам; стих показывается целиком. Проверены десктопные и мобильные страницы, настройки чтения, файлы, публикация и восстановление, SMTP-протокол и опрос. Отчёт: [qa/verification.md](qa/verification.md).

```sh
node tools/check.mjs
node --test tools/*.test.mjs
```

Оригинальные 13 документов сохранены без изменения байтов. Даты и показатели перенесены из предоставленных материалов. Перед публичным запуском владелец должен подтвердить сведения об операторе и обработку данных у выбранного хостинг-провайдера: [qa/legal-notes.md](qa/legal-notes.md). Политика описывает реальные функции сайта; удаление писем из Mail.ru выполняет оператор.
